# gem5 Configs

gem5 configs for full-system X86 Linux simulation.

Every run is driven by a single YAML file (see [`config.yaml`](config.yaml)).

See
[ARCANA-Research/gc-characterization](https://github.com/ARCANA-Research/gc-characterization) for a project that uses these configs.

Note that `common/board/serial.py` is based on gem5's `X86Board`.
